## MISSION METER: `#meter-slot` (INTEGRATION adds `<div id="meter-slot"></div>` as a direct child of `#app`, anywhere after `#game`)
Selector styled: `#meter-slot` (and `#app:has(#meter-slot)` for the grid). It is `position:relative; pointer-events:none; overflow:visible; z-index:3` and in EVERY layout its box is EXACTLY the board frame box (`.board-wrap`: 6.3 x 5.3 cells), verified equal at 1024x576, 800x450, 400x225, 425x812. This is what `meter.css`/`meter.js` already assume (`.mm` hangs off the host: ladder `right:100%`, strip `bottom:100%`, badge corner). Its home grid area is `meter` (empty column/row reserved so the ladder/strip never covers anything).
- Desktop (landscape, height > 300): columns `side | meter | game | side`; area `meter` = full-height column of `--mw = --lw + 8px` with `--lw: clamp(34px,5.2vw,58px)` (51 px at 1024, 41 px at 800); `#meter-slot` is shifted so its left edge = board frame left edge, height = 5.3 cells (about 490 px at 1024x576). meter.js ladder width uses `var(--lw)` (inherited). The board is ~10 % smaller than before because the column is always reserved (no layout jump when free spins start).
- Portrait (aspect <= 11/10): rows `logo | meter | game | info | ctrl`, row `meter` = `--mh` 34 px (26 px strip + 8 px margin). The slot is board-sized (6.3 x 5.3 cells with cell = width/6.5, top = game top + .6 gap; the board is top-aligned in this layout) so the strip sits directly above the grid. If a very short portrait window makes the board height-limited the strip can be a few px wider than the frame. Mascot is a little smaller (54-80 px) in this layout so it covers less of the grid.
- <= 300 px high landscape (400x225): no area; `grid-area:game`, centered, board-sized; `.mm[data-layout=badge]` draws the 34 px badge at the frame corner and the 4 px bar under the frame (about 7 px free under the board).
