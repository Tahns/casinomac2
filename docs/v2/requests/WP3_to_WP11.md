# WP3 (HEROINE) to WP11 (CONTENT-RELEASE): what the build, the art tools and INTERFACES.md need to know

1. **New shipped files** under `frontend_mambo/src/render/heroine/`: `index.js clips.js director.js gaze.js bubble.js heroine.css`, the synced rig `mambo_art.js mambo_outfits.js mambo_rig.js mambo_compat.js` (+ `SYNC.json`), and `fallback_art.js` (about 47 KB, only loaded when the rig fails). All are reached through dynamic `import()` from `src/render/mascot.js` (`./heroine/index.js` -> `./mambo_rig.js`, `./director.js`, `./clips.js`, `./fallback_art.js`, `../../settings.js`), so a bundler/copy step must keep every file of the folder. `mambo_compat.js` is the reference adapter of the art and is NOT imported by the game (it may be dropped from `dist`; the sync keeps it for parity). No `.mjs` is shipped on purpose (a static host may not serve it as a module). `heroine.css` is linked from `index.html` (and auto-loaded by `mascot.js` when missing).
2. **`tools/art/bake_mambo.mjs` / `gen_store_art*.mjs`** read `src/render/mascot.js` as a classic script and call `createMascot(h, { size, variant:'full', pose })` expecting the v1 SVG synchronously. `createMascot` now returns the heroine (asynchronously). Call `createMascotV1` instead (same arguments, still exported; `.replace(/export /g, '')` keeps working because mascot.js has no static import). The tile and the cover should use the heroine: her `inspectrice` idle pose is `fallback_art.js` (`FALLBACK_SVG`, viewBox `60 30 280 556`, self-contained, no script); regenerate with `node tools/sync_heroine.mjs --fallback`, or render the rig with `createHeroine(el, { raf:false, reduced:true, idle:false })` for other costumes and poses.
3. **docs/v2/INTERFACES.md section 3** can be updated with what is now true: `REACT_KINDS` = the 14 frozen kinds + `meter`, `gag` (appended); `react()` returns true when a clip / static pose / costume change started; `info` keys `level ratio at speed ms mission outfit`; `createMascot(host, opts)` options `size crop outfit reduced onCue v1 halftone`; the extra API `mode() ready setCrop setOutfit impl`; `mascotOf(el)`; `createMascotV1`. The full table is in `docs/v2/requests/WP3_to_WP4.md`.
4. **Rules text / Info tab**: nothing about the heroine is shown to the player as a rule. If a "characters" or credits line is wanted, the heroine is "Mambo" (the agent), five costumes: Inspectrice (base), Lab, Trench, Casino, Vault (reserved).
5. **Word screen**: `en_hero.js` rewords 5 lines (mascot.lose / lose.1, fsEnd.3, fsEnd.5, big.2, wire.2); `tests/heroine/text.test.mjs` runs the restricted-word screen in both modes over every `mascot.*` key.
