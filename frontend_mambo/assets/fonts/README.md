# Fonts shipped with Agent Mambo

| File | Family | Author | Licence | Use |
|---|---|---|---|---|
| `LuckiestGuy-Regular.ttf` | Luckiest Guy | Astigmatic (AOETI), via the Google Fonts library | Apache License 2.0 (`LICENSE-LuckiestGuy-Apache-2.0.txt`) | display only: titles, buttons, banners, stamps |

Only one font is embedded (the slot guide allows at most two). Body text, numbers and the HUD use the system stack (`--ui`, `--num` in
`styles.css`). Loaded locally with `@font-face` and `font-display: swap`; no external host. See `docs/v2/CHARTER.md`.
