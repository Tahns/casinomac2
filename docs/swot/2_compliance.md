## Checked and fine
- Disclaimer text identical to CONTRACT.md. Title, aria-labels, tooltips, CSS `content`, loading screen: no restricted words or branding. Only "stake" is the social regex in `social.js`.
- Rules vs math: paytable (all 10 symbols, tiers 5/6-8/9-12/13+), RTP 96.00% and max win 5000x for both modes (recomputed from lookUpTables), 3x vein start, +3 per hit, cap 512, cluster = table x sum of cell multipliers, trigger 4/5/6/7/8+ = 10/12/15/18/20, retrigger 3..8+ = 5/8/10/12/15/18, fuse 8 cells, 1 lit at reveal, blast needs >=3 burnt, S never changed, active in base and free spins, UNLEASH 100x.
- Wins: 0.10, 0.25 stakes (win, bonus, maxwin) display = bet x payoutMultiplier; settle uses RGS `round.payout`. Replay total = round(pm x amount).
- Single place formats money (`money.js`; `render/index.js:52` default is overwritten by `setFormat`).
- Guards: no play below balance (button, Space, autoplay, UNLEASH); end-round only if payout > 0; double click, Space with a button focused (no extra bet change), Space while resuming a round, repeat key: no extra play; autoplay needs a confirm; reload mid-round resumes with bet = round.amount; ERR_ACT never creates a duplicate round; tab hidden during playback completes without extra calls; no external requests.
- `rgs_url` forms (scheme added, bare host https, local http, trailing slash, port) handled; replay URL builds with encoded segments; replay with invalid mode, empty state and fetch failure show a message, no wallet calls.
- Replay and social wording (full `t()` key scan, rules tabs, Fuse Line text, mascot bubbles): clean apart from items 9 and 14.
